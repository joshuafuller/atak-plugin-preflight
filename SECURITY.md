# Security policy

This project is a local pre-flight helper, not an official TAK or TPP service.
Do not submit credentials, signing keys, restricted SDK contents, APKs, or
private Fortify/TPP reports in a GitHub issue or pull request.

For a suspected security defect in this repository, open a private GitHub
security advisory if enabled for the repository. If that is unavailable,
contact the repository owner privately before public disclosure.

Reports produced by this tool may contain source paths and scanner details.
Review them before sharing outside the project.
